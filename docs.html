Quickstart: Streaming Pipeline Ingestion

This guide walks you through provisioning your first multi-region Kafka ingestion sink and executing a zero-latency DAG using the DataForge Python SDK.

1. Install the SDK

pip install dataforge-streaming --upgrade

2. Initialize Client & Execute DAG

# Initialize client with production bearer token
from dataforge import DataForgeClient

client = DataForgeClient(api_key="df_live_sec_9981", region="us-east-1")
pipeline = client.pipelines.create(
source="kafka://production-cluster-01",
sink="snowflake://enterprise_dw.finance",
ai_sanitization=True
)

print(f"Active DAG deployed: {pipeline.id}")
Security & Access

Authentication & Enterprise SSO

DataForge APIs require a bearer token passed via the Authorization: Bearer <token> header. For enterprise workspaces, SAML 2.0 and OIDC federation are fully supported through Okta, Azure AD, and Google Workspace.

Example cURL Request:
curl -X GET https://api.dataforgelabs.io/v1/clusters \
  -H "Authorization: Bearer df_live_sec_9981" \
  -H "Content-Type: application/json"
