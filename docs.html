Quickstart SDK

Python SDK Quickstart

Install the official DataForge Python SDK and initialize your first real-time streaming pipeline in minutes.

# Install via pip
pip install dataforge-sdk
quick_start_pipeline.py
from dataforge import DataForgeClient

# Initialize client with API Key
client = DataForgeClient(api_key="df_live_sec_9981", region="us-east-01")

# Provision a real-time Kafka streaming pipeline
pipeline = client.pipelines.create(
    name="enterprise-tx-stream",
    engine="flink",
    ai_agents=True
)

pipeline.deploy()
print(f"Pipeline successfully deployed. ID: {pipeline.id}")
Authentication

Enterprise SSO & API Authentication

All API requests must include a valid Bearer token in the authorization header. For organization-wide access, configure SAML/Okta enterprise SSO through the admin console.

curl -X GET https://api.dataforgelabs.io/v1/clusters \
-H "Authorization: Bearer df_live_sec_9981" \
-H "Content-Type: application/json"
